Privacy policy / Политика конфиденциальности

Версия / Version 2026-10-17.1 · 17 октября 2026 / October 17, 2026

Who operates the tool / Кто использует приложение

Queen Social Growth is a private tool operated by the owner of the Queen Kassandra brand to manage that owner’s X and Threads presence. It is not an open registration service. Contact the operator using the address below.

Queen Social Growth — закрытый инструмент владельца бренда Queen Kassandra для управления его присутствием в X и Threads. Открытой регистрации пользователей нет. Связаться с владельцем можно по адресу ниже.

Information processed / Обрабатываемые данные

When an account is connected, the tool stores its username, platform identifiers, granted permissions, token expiry and encrypted access credentials. It may store the owner’s drafts, translations, uploaded media, approval history, publication identifiers, and metrics available from the platform. Public discussion and competitor records may include usernames, post text, links, dates and available engagement counts. It does not obtain platform passwords through OAuth.

При подключении аккаунта приложение хранит имя, идентификаторы платформы, выданные права, срок токена и зашифрованные реквизиты доступа. Оно может хранить черновики владельца, переводы, загруженные медиа, историю согласований, идентификаторы публикаций и доступные метрики. Записи публичных обсуждений и конкурентов могут содержать имена, тексты, ссылки, даты и доступные показатели активности. OAuth не передаёт приложению пароли социальных сетей.

Purpose and access limits / Цели и ограничения доступа

Information is used to plan and approve original content, identify relevant conversations, compare observed results and maintain a reliable publication history. Access is limited by the platform, granted permissions and app approval status. Missing data remains unknown. The tool does not sell platform data, run advertising audiences, or automate bulk replies, likes or follows. Each publication requires the owner’s approval of the exact preview.

Данные используются для подготовки и согласования собственного контента, поиска уместных обсуждений, сравнения наблюдаемых результатов и надёжной истории публикаций. Доступ ограничен платформой, правами и статусом одобрения приложения. Недоступные данные остаются неизвестными. Приложение не продаёт данные платформ, не создаёт рекламные аудитории и не выполняет массовые ответы, лайки или подписки. Для каждой публикации требуется согласование точного предпросмотра владельцем.

Storage and security / Хранение и защита

In the current installation, app data is stored on the operator’s Windows computer. API credentials are encrypted in storage; the encryption key is kept locally. Content, analytics and audit records in the SQLite database are not themselves encrypted by the application. Full exported recovery archives are password encrypted; ordinary database backups are not a substitute for device protection. Access to the tool requires authentication. No system can guarantee absolute security.

В текущей установке данные находятся на Windows-компьютере владельца. API-реквизиты зашифрованы при хранении; ключ находится локально. Контент, аналитика и журнал в SQLite не шифруются самим приложением. Полные экспортируемые архивы восстановления защищены паролем; обычные копии БД не заменяют защиту устройства. Для доступа к приложению нужна авторизация. Ни одна система не гарантирует абсолютной безопасности.

External services / Внешние сервисы

Connected X and Threads APIs receive the requests necessary for the enabled functions. If the operator separately enables OpenAI, selected discussion, profile or draft context may be sent for AI assistance. If Telegram is enabled, selected previews, reports and approval messages may be sent through Telegram. The tool does not send platform access tokens or platform passwords to AI prompts. Those providers apply their own terms and privacy policies. No platform data is included in this static policy website.

API подключённых X и Threads получают запросы, необходимые для включённых функций. При отдельном включении OpenAI выбранный контекст обсуждения, профиля или черновика может отправляться для AI-помощи. При включении Telegram выбранные предпросмотры, отчёты и сообщения согласования могут передаваться через Telegram. Токены платформ и их пароли не включаются в AI-запросы. Провайдеры применяют собственные условия и политики конфиденциальности. Этот статический сайт политики не содержит данных платформ.

Cookies, links and logs / Cookie, ссылки и журналы

The app uses an authentication cookie and operational records for security, approvals, delivery attempts and API budget controls. Short links created by the owner record aggregate HTTP requests, including possible bots; they are not unique-visitor measurements. These policy pages do not use analytics scripts or set cookies themselves. If published on GitHub Pages, GitHub logs visitors’ IP addresses for security purposes under its own privacy statement.

Приложение использует cookie авторизации и технические записи для безопасности, согласований, попыток отправки и контроля API-бюджета. Короткие ссылки владельца считают HTTP-запросы, в том числе возможных ботов; это не измерение уникальных посетителей. Сами страницы политики не используют аналитические скрипты и не устанавливают cookie. При размещении на GitHub Pages GitHub сохраняет IP-адреса посетителей в целях безопасности согласно своей политике конфиденциальности.

Retention / Сроки хранения

Saved content, analytics and history remain until the operator removes them; there is no automatic expiry for every record. Database backups rotate by a configured number of files, with a default of 30 copies, not a guaranteed number of days. Manually exported archives and copies outside the app are controlled separately by the operator. Data removal requests must therefore cover both active records and retained copies where applicable.

Сохранённый контент, аналитика и история остаются до удаления владельцем; автоматического срока для каждой записи нет. Копии БД ротируются по настроенному количеству файлов: по умолчанию 30 копий, а не гарантированное число дней. Ручные архивы и копии вне приложения контролируются владельцем отдельно. Поэтому запрос на удаление должен учитывать как действующие записи, так и сохранённые копии, если это применимо.

Your requests and disconnection / Обращения и отключение

Contact the operator to request information about stored data, correction or deletion, identifying the relevant account or public post. Do not send passwords, tokens or identity documents by email. The operator may ask for proportionate evidence of account ownership before acting. Removing the app’s access in the platform settings stops future access but does not automatically erase locally saved records or remove posts already published on the platform. See the separate data-deletion instructions.

Для уточнения состава данных, исправления или удаления напишите владельцу, указав соответствующий аккаунт или публичную публикацию. Не отправляйте по email пароли, токены и документы личности. Перед действием владелец может запросить соразмерное подтверждение принадлежности аккаунта. Отзыв доступа в настройках платформы прекращает дальнейший доступ, но сам по себе не стирает локальные записи и не удаляет уже опубликованные посты на платформе. См. отдельные инструкции по удалению данных.
